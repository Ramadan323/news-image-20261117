One image that sums up the world's news of Tuesday 17 November 2026: an
editorial front page led by Ukraine's strike on the Crimean (Kerch) Bridge,
which Kyiv called "unprecedented", with four more of the day's stories below
— a Russian military plane crash in Siberia that killed all 19 on board, the
United States losing its measles elimination status after 26 years, the US
blocking China's remote access to AI chips after the Nvidia scandal, and
Mongolia's president resigning amid a corruption scandal. All artwork was
drawn from scratch with Python PIL (shapes and typography only); no
photograph or borrowed artwork is used. Sources: BBC, Reuters, AP,
Al Jazeera.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` (1024x1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR/entry.png`.
